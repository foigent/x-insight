# Security reporting

Do not put exploit details, credentials, private evidence, or customer data in a public issue or pull request.

Private vulnerability reporting for this repository is **not verified as enabled**. No security mailbox or response-time commitment is published here. If GitHub displays an enabled **Report a vulnerability** channel in this repository's Security tab, use that verified private channel. Otherwise, open a minimal issue asking maintainers for a private reporting route, without vulnerability details, affected private identities, or a reproducer. Wait for an agreed private route before sending sensitive material.

Once a private route is established, useful information includes the affected commit/version, trust boundary, required privileges, expected and observed behavior, a minimized synthetic reproduction, and impact. Do not send a live token or raw production database.

The current development candidate has no published long-term support window. Fix and release eligibility is reviewed against the exact source and artifact. Source access does not authorize testing a deployment, weakening grants, bypassing release signatures, or using customer data.
